# 🚨 Emergency Command System

An AI-powered Emergency Command System built with the **MERN Stack** that intelligently classifies emergency reports and routes them to the appropriate department (Police, Fire Brigade, or Hospital) in real time.

## ✨ Features

- 🤖 AI-powered emergency classification
- 🚓 Police, 🚒 Fire Brigade & 🏥 Hospital dashboards
- 📍 Real-time emergency management
- 🔐 Secure JWT Authentication
- 📊 Role-based access
- ☁️ MongoDB Database
- ⚡ RESTful API

## 🛠️ Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- JWT Authentication
- Tailwind CSS
- Gemini AI API

## 📂 Project Structure

```
client/
server/
```

## ⚙️ Installation

```bash
git clone https://github.com/your-username/emergency-command-system.git
cd emergency-command-system

# Backend
cd server
npm install

# Frontend
cd ../client
npm install
```

## ▶️ Run the Project

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
```
